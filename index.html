✅ Чекліст виконання: «Як я це зробив»
  • Крок 1. Зареєструвався на безкоштовному хостингу (GitHub Pages / zzz.com.ua / Netlify / Vercel).
  • Крок 2. Отримав доменне ім'я, що містить моє прізвище латиницею (наприклад, melnyk10a.github.io).
  • Крок 3. Завантажив файл index.html у кореневу папку сервера (public_html або корінь репозиторію).
  • Крок 4. Відкрив сайт за URL-адресою у браузері та надіслав посилання вчителю.
🛠️ Як персоналізувати цей файл перед завантаженням?

Відкрий файл index.html у Блокноті, VS Code або прямо в редакторі GitHub і зміни виділені рядки:

<!-- 1. Заголовок на вкладці браузера -->
<title>Мій перший сайт — Прізвище Ім'я</title>

<!-- 2. Головний колір оформлення у блоці :root -->
--accent: #3b82f6; <!-- Спробуй #10b981 або #8b5cf6 -->

<!-- 3. Головний заголовок на сторінці -->
<h1>Вітаю! Це мій перший сайт в Інтернеті</h1>
